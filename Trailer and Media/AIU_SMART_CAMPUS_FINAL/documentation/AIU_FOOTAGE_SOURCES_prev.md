# AIU_FOOTAGE_SOURCES.md

**Result: no real AIU footage or photographs are used in this trailer.** None could be acquired legitimately in this environment (details below). Every real-AIU slot is a clearly labelled placeholder; nothing is presented as AIU footage.

## Why nothing was downloaded
- The production sandbox has no direct internet access. It can read page *text* from aiu.edu.eg but cannot fetch images or video files.
- The browser tools were pointed at https://aiu.edu.eg/ and the page would not load there (navigation silently reset to a blank tab), so site-hosted media could not be enumerated or saved.
- Per your instructions, nothing was taken from YouTube, Instagram, Facebook or X, and no media was assumed to be reusable just because it is public.

Drop them into a folder and the timeline slots listed in TRAILER_PRODUCTION_REPORT.md can be replaced directly; record each in the table above.
